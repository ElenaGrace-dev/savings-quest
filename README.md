# Savings Quest

A local-first weekly budgeting PWA with:

- Typical weekly take-home baseline of $357.84
- Smart Extra Pay for higher-pay weeks
- Bill envelopes with weekly contribution history
- Envelope borrowing with next-week Flexible repayment + 1%
- Affirm and Klarna payoff tracking
- Smart payoff targeting
- Responsive phone + desktop layout
- Black + purple dark mode by default
- Light mode toggle
- Installable PWA support
- Offline caching after first visit

## GitHub Pages

In the repository, open **Settings → Pages** and set:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Then save. The site will be available at:

`https://elenagrace-dev.github.io/savings-quest/`
